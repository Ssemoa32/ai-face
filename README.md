## 🚀 التشغيل

1. نزّل المشروع أو استنسخه:
   ```bash
   git clone https://github.com/Ssemoa32/ai-fice.git
   cd ai-face
   ```
2. افتح `index.html` في متصفح حديث. ولأفضل توافق مع ميزات الصوت وطلبات الشبكة، شغّله من خادم محلي مثل إضافة Live Server أو:
   ```bash
   python -m http.server 8000
   ```
3. افتح `http://localhost:8000`.
4. اضغط زر 📡 لاختيار الاتصال وضبط رابط الخادم أو مزوّد الذكاء الاصطناعي.
5. اضغط 🎤 للتحدث، 📋 لإدارة المهام، أو 😐 لتغيير تعبير الوجه يدويًا.

> قد يتطلب التعرف على الصوت اتصالًا آمنًا (`HTTPS` أو `localhost`) ومتصفحًا يدعم Web Speech API. يختلف دعم الميزة بين المتصفحات.

## 🔌 الاتصال بالذكاء الاصطناعي

يدعم التطبيق وضعين من الواجهة:

- **خادم خلفي:** يرسل التطبيق النص إلى `POST /api/chat`، ويمكن فحص توفر الخادم عبر `GET /api/health`.
- **اتصال مباشر بمزوّد API:** يرسل التطبيق الطلب مباشرة من المتصفح إلى المزوّد المحدد في الكود.

يتوقع التطبيق ردًا JSON يتضمن `reply`، ويمكن أن يتضمن `mood` و`intensity` و`duration`. راجع `index.html` لمعرفة أسماء النماذج وعناوين API المستخدمة.

### 🔐 تنبيه أمني مهم

الاتصال المباشر من المتصفح **غير مناسب لمفاتيح API السرية**: المفتاح المحفوظ في `localStorage` يمكن للمستخدم أو لأي JavaScript يعمل على الصفحة الوصول إليه، وقد يؤدي نشر التطبيق إلى كشفه. لا تضع مفاتيح حقيقية في المستودع أو في ملفات الواجهة. للاستخدام الفعلي، استخدم خادمًا خلفيًا يحتفظ بالمفتاح في متغيرات بيئة، ويتحقق من الطلبات ويطبق حدودًا للاستخدام. إذا سبق أن شاركت مفتاحًا أو أضفته إلى المشروع، أبطله وأنشئ بديلًا.

## 🧰 التقنيات

- HTML وCSS وJavaScript دون إطار عمل.
- Canvas API للرسم والتحريك.
- Web Speech API للإدخال الصوتي المدعوم.
- `localStorage` لحفظ المهام وإعدادات الاتصال على الجهاز.
- Fetch API للتواصل مع الخادم أو خدمة الذكاء الاصطناعي.
